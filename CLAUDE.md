# Project Instructions

## Scope
- Build a front-end mockup using plain HTML, CSS, and JavaScript.
- No backend, frameworks, build tools, or unnecessary dependencies.
- Start with the homepage; other designed pages will be added later.

## Structure
- Keep shared tokens, typography, and common styles reusable across pages.

## Design source
- Use the approved Figma desktop design, components, and original assets.
- There is no mobile design. Propose mobile adaptations for approval.

## Approval rules
- Before changing a design decision to fix a responsive or implementation
  issue, explain the issue and proposed fix, then wait for approval.
- Ordinary coding fixes that do not change the approved design may proceed.
- Do not modify Figma or deploy anything without approval.

## Communication
- Keep responses brief.
